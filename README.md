# Exploratory Data Analysis on a Cars Dataset

## Overview
Python EDA project using the UCI Auto MPG dataset. It checks data quality, cleans missing values, calculates descriptive statistics, flags potential outliers, creates six charts, prints evidence-based findings, and generates a PDF report.

## Dataset
[UCI Auto MPG Dataset](https://archive.ics.uci.edu/dataset/9/auto+mpg)

The dataset includes fuel economy, cylinders, displacement, horsepower, weight, acceleration, model year, origin and car name. It does not include car prices.

## Requirements
Install Python 3, then run:
```bash
python -m pip install -r requirements.txt
```

## Run
Ensure internet access is available, then run:
```bash
python Jyothsna_Cars_EDA_Project.py
```
The script downloads the dataset and creates `Jyothsna_Cars_EDA_Report.pdf` plus charts and CSV summaries in `eda_outputs/`.

## Deliverables
- `Jyothsna_Cars_EDA_Project.py`
- `Jyothsna_Cars_EDA_Report.pdf` (generated by running the script)
- `README.md`
